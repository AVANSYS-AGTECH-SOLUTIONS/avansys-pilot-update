# AvanSys Pilot · versiones

Versiones publicadas de AvanSys Pilot, la app de AvanSys que corre en el control DJI RC Pro Enterprise y vuela el Mavic 3M.

Cada release trae el APK firmado por AvanSys y `latest.json`, que la app consulta para avisar que hay una versión nueva.
Se publican con `scripts/publicar-version.sh` del repo de la app. Acá no hay código.
